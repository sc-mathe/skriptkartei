# Skriptkartei

Persönliche Karteikarten-App (Web-App/PWA) mit Wiederholungen nach FSRS-5.
Funktioniert offline; Karten und Lernstand werden über Supabase synchronisiert.

Dieses Repository enthält nur den Programmcode. Karten und Lernstand liegen privat
in der Datenbank und sind nur nach Anmeldung mit dem freigeschalteten Konto lesbar.
